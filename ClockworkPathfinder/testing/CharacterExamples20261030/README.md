# Character Examples (Dated: 2026-10-30)

This directory contains full character builds, benchmark test examples, and comparative matrices created on **October 30, 2026**, completely recreating and superseding the October 28 suite (`CharacterExmples20261028/`).

## Core Updates in the 2026-10-30 Suite

1. **The 10-Point Edge System (`edges.md`):**
   - Characters start at Status 0 (Warrens Outcast, 0 Edge cost) with a flat 10-point budget.
   - Status tier costs: Status 1 (1 pt), Status 2 (2 pts), Status 3 (3 pts), Status 4 (4 pts), Status 5 (5 pts).
   - Wall Merchants (Status 6) and Great Nobles (Status 6) pay **7 points** (Base 6 + 1 point armed retainer surcharge).
   - Single-purchase limit enforced on all edge traits and proficiency boosts.
   - Proficiency steps: 3 points for max Expert, 5 points for max Master (requires existing native Expert).
2. **Citizen Bulwark Slots:**
   - Every character profile lists their 3 designated personal items (weapons, armor, tools, crests) legally shielded from municipal confiscation.
3. **Wound & Trauma Bands:**
   - Explicit Mortal Threshold ($\lfloor \text{HP}/4 \rfloor$) and Critical Threshold ($\lfloor \text{HP}/2 \rfloor$) step bands on all stat blocks.
4. **Radiant & Action Point (AP) Economy:**
   - Active AP base pools by class tier, Level 5 scaling, Battery Surge additions, and disciplined tag weapon costs.
5. **Weapon Traits & Combat Mandates:**
   - Fair Steel Mandate applied to civil ward rapiers.
   - Cartridge firearms accurately reflect the +1 reload action penalty when wielding a shield.
   - Cumbersome and Arclean shock mechanics integrated into equipment notes.
