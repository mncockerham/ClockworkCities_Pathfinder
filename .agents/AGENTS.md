# Clockwork Cities Pathfinder — Project Rules

- Goal: convert the Clockwork Cities setting to a heavily modified Pathfinder Core rule set.
- Current Focus: Healing & Wound Thresholds (`AISummary/20_Healing.md`), Equipment systems (`ClockworkPathfinder/Equipment/`), and Class & Adversary Frameworks.
- Primary reference: `AISummary/WorldSummary.md`. Start here for all design work; only open `SourceDocuments/` when exact wording or detail is needed.
- `SourceDocuments/` = guidance only. `SourceDocuments/OlderIdeas/` = legacy reference; do NOT edit or delete, do NOT reuse its mechanics.
- All mechanics from source docs are discarded; world facts (money, social class, wealth/status, exposure, humanity types) stay canon.
- New rules go in `AISummary/` as Markdown during rules setup (end documents for players will go in `ClockworkPathfinder/` later) and override any [LEGACY] note in the summary.
- Base system: Pathfinder 2e Remaster (ORC). Never reproduce PF text; cite `[Book p.#]` and document only changes/new material. Conventions in `AISummary/00_RulesFoundation.md`.
- Keep `AISummary/` files compressed and AI-oriented; update them when design decisions change canon.
- Standard terms: Aither, Neither, Zone, Neithercrete, Arclean.

## Class & Actor Tiers (PC, NPC, Creature Class)
- **Universal Base Framework:** Core classes are intended for **PCs, NPCs, and Adversaries** alike to use.
- **NPC Classes Subcategory:**
  - Designed for weaker civilian/support archetypes (e.g., Commoner, Craftsman, Laborer, Professional, Sailor (Air & Sea)) to flesh out the world.
  - Signifies that in most campaigns, they lack sufficient flexibility in abilities and scope of use to make a viable PC.
  - **Power Scaling & Player Intent:** Kept **a few levels weaker** than standard PC/NPC classes so they fulfill background/civic roles without crowding out full classes, and specifically to ensure players do not become too focused on playing them (can be powered up by the GM if needed).
- **Creature Class Subcategory:**
  - If more powerful adversaries, wild beasts, or engineered abominations are required outside the normal humanoid class framework, they are added under **Creature Class** (`ClockworkPathfinder/Classes/NPC/creature class/`).
