# Clockwork Cities — Rules Foundation

## Base System
- **Pathfinder Second Edition Remaster** (ORC License).
- Core books assumed owned: *Player Core*, *Player Core 2*, *GM Core*, *Monster Core* (add others as adopted).
- These documents **do not reproduce** Pathfinder text. They reference the source and record only **changes** and **new material**.

## Citation Format
`[Book p.###]` — e.g. `[Player Core p.42]`. Abbreviations allowed after first use: PC1, PC2, GMC, MC.

| Status tag | Meaning |
|---|---|
| **Unchanged** | Use as written; reference only. |
| **Modified** | Base rule applies except as noted. |
| **Replaced** | Base rule does not apply; full Clockwork rule given. |
| **Removed** | Not available in the setting. |
| **New** | Clockwork-only rule. |

## Precedence
1. Specific Clockwork rules (a character ability, location, item, or world event) override general Clockwork rules.
2. Clockwork rules override Pathfinder rules.
3. Anything not addressed uses Pathfinder Remaster as written.

## Magic (headline change)
- Magic is the **largest departure** from Pathfinder. Classes that rely on magic are heavily modified in both **what they can do** and **why it works** (in-world explanation tied to Aither / Neither / Zone; to be defined).
- **Modified magic classes are capped at class level 5** for most NPCs (character level in that class, not spell rank).
- **PCs may not take a magic class as their main class**; they may only gain access by **multiclassing** (Pathfinder multiclass archetype dedications).
- Exceptions are expected: specific characters, abilities, or world changes may break these limits.
